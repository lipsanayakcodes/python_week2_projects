# Python Internship Projects

This repository contains the Python assignments and mini project completed as part of my internship.

## Projects

### 1. Contact Book Using Dictionary

A simple contact book application using Python Dictionary.

**Features:**

* Add contact
* Search contact
* Update contact
* Delete contact
* Display contacts

### 2. Word Counter from Text File

A Python program that reads a text file and counts:

* Number of words
* Number of lines
* Number of characters

### 3. JSON File Reader

A Python program that loads JSON data from a file and displays the information in a formatted way.

**Features:**

* Read JSON file
* Load JSON data using Python
* Display formatted output

### 4. Student Management System

A mini project for managing student records using a CSV file.

**Student Information:**

* Roll Number
* Name
* Marks

**Features:**

* Add student
* Search student
* Delete student
* Display all students
* Permanently save data in CSV file

## Technologies Used

* Python
* CSV
* JSON
* File Handling
* Dictionary
* Functions
* Loops
* Conditional Statements
